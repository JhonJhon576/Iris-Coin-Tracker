# 🤖 nodal-agentos - Plan Tasks, Watch Agents Work

## 🚀 What Is This?

nodal-agentos is a desktop app that helps you organize your work and let AI agents do the heavy lifting. Think of it as a mission control center for your projects. You write down what needs to be done, and the app hands those tasks to Claude Code agents who work through them while you watch everything happen in real time.

It works across all your projects, so you can manage everything from one place. Right now, it's available for Mac computers and is in an early testing phase, which means it's functional but still being refined.

## 🎯 Who Is This For?

This app is perfect for anyone who juggles multiple projects and wants to automate repetitive coding tasks. You don't need to be a programmer to understand what's happening—the interface shows you clearly what each agent is doing, step by step. If you've ever wished you had extra hands to handle your to-do list, this is for you.

## ✨ Key Features

- **Task Planning Made Simple** - Organize your work into clear, manageable tasks with a straightforward interface
- **AI Agent Assignment** - Hand tasks to Claude Code agents with just a few clicks
- **Live Run Tracking** - Watch agents execute tasks in real time, seeing exactly what they're doing
- **Multi-Project Support** - Keep all your different projects in one view and switch between them easily
- **Git Worktree Integration** - Work on multiple versions of your code simultaneously without conflicts
- **Built for Mac** - Designed to feel native and intuitive on macOS

## 🛠️ How It Works

1. **Create a Task** - Write down what needs to be done in plain language
2. **Assign It** - Choose which agent should handle the task
3. **Watch It Happen** - The agent gets to work, and you can follow every step in real time
4. **See Results** - When the agent finishes, you'll see exactly what was accomplished

It's like having a team of assistants who never sleep, never get tired, and follow your instructions precisely.

## 🖥️ First Steps

When you first open nodal-agentos, you'll see a clean dashboard. Here's what to do:

2. **Name It** - Give it a clear name so you know what it's about

## ❤️ Frequently Asked Questions

**Do I need to know how to code?**

No! The app is designed so anyone can describe what they want in plain language, and the AI understands it.

**Can I run multiple tasks at once?**

Absolutely. You can have several agents working on different tasks simultaneously.

**What happens if there's a mistake?**

You can see every action an agent takes. If something goes wrong, you can stop the task, review what happened, and adjust your instructions.

**Is my data safe?**

Yes. Your tasks and project information stay on your computer. Only the actual task instructions are sent to Claude's servers to be processed.
